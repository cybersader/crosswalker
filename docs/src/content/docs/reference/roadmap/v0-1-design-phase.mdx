This is the archived **Foundation / design phase** section of the [roadmap](/crosswalker/reference/roadmap/). It ran from the [vision alignment decisions](/crosswalker/agent-context/zz-log/2026-04-03-vision-alignment-decisions/) of 2026-04-03 to the close of the design phase on 2026-05-04, when five fresh-agent research challenges (Ch 20 to 24) resolved the last named architectural questions. Implementation of v0.1 began the same day; its live status is on the [milestone hub](/crosswalker/reference/roadmap/milestones/).

Moved here from the living roadmap on 2026-10-03, because the roadmap page should show current work first. Nothing on this page is current status; dates are the dates of the facts they describe. The list of what is still open is in [What carried forward](#what-carried-forward).

## Design phase closed (2026-05-04)

**Architectural commitments locked on 2026-05-04** (the authoritative list is the v0.1 commitments table in the repository's agent instructions; each item links its synthesis log):

- [Schema-as-primitive](/crosswalker/concepts/etl-and-import/): the Tier 1 schema is the load-bearing contract; engine and ETL are convenience
- Closed 5-mechanism recipe grammar (source: spec/recipe.schema.json § mechanisms): `folder | file | heading | tag | wikilink` × layout × also_emit × graph_edges, with `render(Recipe, ConceptIdentity) → Address` as the single coupling point ([Ch 22 synthesis](/crosswalker/agent-context/zz-log/2026-05-04-target-structure-synthesis/))
- TypeScript in-plugin engine for v0.1; an optional Python producer reserved for v0.5+ ([Ch 23 synthesis](/crosswalker/agent-context/zz-log/2026-05-04-bundle-engine-language-synthesis/)). Its "main thread, no Web Workers" clause was narrowed on 2026-10-03 to the import engine only ([Tier 2 worker persistence synthesis §3](/crosswalker/agent-context/zz-log/2026-10-03-tier2-worker-persistence-synthesis/))
- [Tier 2](/crosswalker/concepts/system-architecture/) substrate on `@sqlite.org/sqlite-wasm` + `sqlite-vec`; libSQL, Turso Cloud and Limbo rejected ([Ch 24 synthesis](/crosswalker/agent-context/zz-log/2026-05-04-tier-2-substrate-synthesis/)). `sqlite-vec` was later deferred to the 2026-11-06 revisit ([WASM-A pivot synthesis](/crosswalker/agent-context/zz-log/2026-05-06-wasm-a-pivot-synthesis/))
- Runtime-agnostic recipe schema ([Ch 23 synthesis §4](/crosswalker/agent-context/zz-log/2026-05-04-bundle-engine-language-synthesis/#4-the-most-important-commitment-runtime-agnostic-recipe-schema))
- Output query layer: Bases (Dataview removed)

Machine-readable contracts shipped that day: `spec/tier1.schema.json` + `spec/recipe.schema.json`; dev infrastructure `tools/generate-fixtures.ts` + `bun run fixtures`. Full state: [2026-05-04 import engine design log](/crosswalker/agent-context/zz-log/2026-05-04-import-engine-design/).

## Architectural safety guarantee (2026-05-02)

**Tier 1 (canonical files) is the source of truth. Tier 2 and Tier 3 are projections, fully deletable and recoverable from Tier 1.** This still holds and is the reason Tier 2 can be shipped without trapping the user. See [v0.1 stack-pivot log §2](/crosswalker/agent-context/zz-log/2026-05-02-v0-1-initial-stack-pivot/#2-the-architectural-safety-guarantee-load-bearing-principle).
