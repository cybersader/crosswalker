## What it is

:::note[In Crosswalker]
The typed mapping table (seven columns, source: `STRM_COLUMNS` in `src/export/strm-tsv-exporter.ts`) is both exported and, since 2026-10-03, imported. A set's [release record](/crosswalker/concepts/terminology/#release-record) travels beside the table as `<name>.mapping-set.json`. See the [slice 2 decision log](/crosswalker/agent-context/zz-log/2026-10-03-mapping-set-typed-table-and-recipe-synthesis/) for what the table cannot carry.
:::

STRM (Set Theory Relationship Mapping) is a methodology for describing how controls in one compliance framework relate to controls in another. It uses 5 formal set-theory relationships.
